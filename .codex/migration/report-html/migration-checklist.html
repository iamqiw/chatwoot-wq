Must-pass 验收清单

  1. 会话状态、优先级、分配、标签、last_seen 节流与事件广播语义一致。
  2. 消息类型/内容类型/状态枚举与首响统计口径一致。
  3. 联系人唯一性与格式校验一致（email/phone/identifier）。
  4. Inbox 的 active_bot 判定、可分配人范围、回调 URL 规则一致。
  5. AutomationRule 条件/动作白名单与 AND/OR 运算符校验一致。
  6. Macro 可见性和执行权限一致（global/personal + author/admin）。
  7. Campaign 类型推导、URL 校验、触发链路、渠道执行策略一致。
  8. HelpCenter portal/article 状态机、语言继承、排序策略一致。
  9. Pundit 关键策略边界一致（Conversation/Contact/Inbox/Campaign/AutomationRule）。
  10. Sidekiq 调度、重试、死信、日志可观测能力一致。

建议的执行顺序

  1. 先完成 AUTH + CONV + CRM 主链路。
  2. 再补 AUTO + INBOX + CMP + HC。
  3. 最后完成 ACL + ASYNC + EE（Captain/SLA/审计）回归。
