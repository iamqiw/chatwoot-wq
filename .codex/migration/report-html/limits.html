当前环境仍受限项

  1. 第三方渠道真实联调（WhatsApp/Facebook/Instagram/Line/Twitter）受凭据和公网回调限制，无法完整闭环截图。

风险控制建议

  • 所有受限能力必须有“替代验证证据”：路由、控制器、策略、服务、任务、日志。
  • 迁移到 Java 后优先补集成沙箱（第三方回调模拟器 + 契约回放）。
  • 针对 EE 功能引入 feature toggle 与数据种子，避免环境导致误判。
