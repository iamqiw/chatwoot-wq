分析结论

  • Captain 不是单一“聊天机器人”，而是 配置台 + 运行时 + 异步管道 + 计费/配额 的组合系统。
  • V1 以单助手为主；V2 引入多 Agent 编排（Assistant + Scenarios）和 Tool handoff。
  • 业务关键不是页面，而是状态切换时机：pending/open/resolved、handoff、usage 扣减。
